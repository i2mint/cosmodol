cosmodol¶

Access Azure Cosmos DB (NoSQL/Core API) through a Mapping interface.

cosmodol exposes Azure Cosmos DB as dol-style Mapping / MutableMapping interfaces, layered over the official azure-cosmos SDK.

Quick start:

from cosmodol import cosmos_store

store = cosmos_store(
    connection_string="AccountEndpoint=https://localhost:8081/;AccountKey=...",
    database="mydb",
    container="mycontainer",
    partition_key_value="tenant-X",
)

store["k1"] = {"name": "Alice", "age": 30}
store["k1"]              # → {"id": "k1", "<pk>": "tenant-X", "name": "Alice", "age": 30}
"k1" in store            # → True
del store["k1"]

See misc/docs/architecture.md for the layered design.

If your Cosmos account was provisioned with the MongoDB API, use pymongo + mongodol directly — this package only targets the NoSQL/Core API.

cosmodol.add_container(db_store, name, *, partition_key_path='/id', throughput=None, indexing_policy=None, default_ttl=None, unique_key_policy=None, conflict_resolution_policy=None, **extra)[source]¶

Create a container named name (in the caller’s key space) in db_store.

Goes through db_store[name] = <the settings>, so every layer maps, scopes or refuses the name as usual; the leaf creates the container from the arguments given here (the value a layer passes down is ignored).

Parameters:

  • db_store – A CosmosDatabase, or a dol wrapper around one.

  • name (str) – Container name, as db_store[name] would take it.

  • partition_key_path (str) – Partition-key path (e.g. "/id", "/tenantId"). Defaults to "/id" per misc/docs/design_decisions.md §3.

  • throughput (Optional[int]) – Provisioned RU/s (e.g. 400). None uses the database’s shared throughput if any, otherwise the account default.

  • indexing_policy (Optional[dict]) – Standard Cosmos container kwargs.

  • default_ttl (Optional[int]) – Standard Cosmos container kwargs.

  • unique_key_policy (Optional[dict]) – Standard Cosmos container kwargs.

  • conflict_resolution_policy (Optional[dict]) – Standard Cosmos container kwargs.

  • **extra – Forwarded to DatabaseProxy.create_container.

Returns:

The SDK’s ContainerProxy.

cosmodol.batch_items(store, operations, *, unguarded_patch=False)[source]¶

Transactional batch within the store’s partition, in the caller’s key space.

Each operation is (op, key) or (op, key, value) (op one of BATCH_OPS), optionally followed by a dict of per-operation SDK keyword arguments such as {"if_match_etag": etag}:

[("upsert", "a", {"v": 1}), ("replace", "b", {"v": 2}), ("delete", "c")]

Each create/upsert/replace is collected through store[k] = v and each delete through del store[k], so every layer maps, checks or refuses it as usual; nothing is sent until all operations are collected, then they commit as one transaction. Bodies get the leaf’s usual id / partition-key injection. On a wrapped store, every key a read, replace, patch or delete targets must be in the store (one point read each), unless an earlier create/upsert of the same batch makes it. read and patch keys are mapped with each layer’s _id_of_key; patch operations are refused on a wrapped or subclassed store unless unguarded_patch=True (no layer’s write logic can run for a patch). The SDK’s raw (op, args, kwargs) triples are not accepted here, because the ids inside them are opaque to any key mapping; use cosmodol.batch(container, triples, partition_key).

Return type:

list[dict]

cosmodol.cosmos_store(*, database, container, connection=None, credential=None, connection_string=None, endpoint=None, key=None, partition_key_value=None, partition_key_path=None, value_codec=None, strip_system_fields=True)[source]¶

Build a ready-to-use Cosmos store (CosmosItems or CosmosPartitionedItems).

The store flavor is chosen based on which partition-key kwarg is passed:

  • partition_key_value=... → CosmosItems (keys = id strings, fixed partition).

  • partition_key_path=... → CosmosPartitionedItems (keys = (pk, id) tuples).

  • Neither given → raises ValueError.

Parameters:

  • database (str) – Database name.

  • container (str) – Container name.

  • connection (Union[CosmosConnection, Any, None]) – A CosmosConnection (or anything from_anything accepts) to reuse a client. Mutually exclusive with explicit credential kwargs.

  • credential (Any) – Forwarded to CosmosConnection when connection is None.

  • connection_string (Optional[str]) – Forwarded to CosmosConnection when connection is None.

  • endpoint (Optional[str]) – Forwarded to CosmosConnection when connection is None.

  • key (Optional[str]) – Forwarded to CosmosConnection when connection is None.

  • partition_key_value (Any) – Fixed partition key value → returns CosmosItems.

  • partition_key_path (Optional[str]) – Partition key property path → returns CosmosPartitionedItems.

  • value_codec (Optional[Callable]) – A decorator that, given a class, returns a wrapped class. Typically a partially-applied dol.wrap_kvs(...).

  • strip_system_fields (bool) – Strip Cosmos system fields from returned items.

Returns:

A CosmosItems or CosmosPartitionedItems instance, possibly codec-wrapped.

cosmodol.delete_container(db_store, name, *, force=False)[source]¶

Drop container name (in the caller’s key space); force empties it first.

Without force this is del db_store[name], which refuses a non-empty container. With force=True every item is deleted, one point delete each, and then the container is dropped, through del db_store[name] so every layer maps, scopes or refuses it as usual. Not recoverable without a Cosmos backup.

Return type:

None

cosmodol.delete_database(account_store, name, *, force=False)[source]¶

Drop database name (in the caller’s key space); force drops its containers.

Without force this is del account_store[name], which refuses a non-empty database. Not recoverable without a Cosmos backup.

Return type:

None

cosmodol.partition(store, pk_value, *, wrap=None)[source]¶

Narrow a CosmosPartitionedItems to one partition; zero round-trips.

On an unwrapped store this returns a CosmosItems sharing the parent’s settings.

A wrapped parent’s transforms cannot be carried onto the child automatically (the parent’s keys are (pk, id) tuples, the child’s are ids), so a wrapped store is refused unless you say how to wrap the child:

sub = partition(redacted_store, "tenant-1", wrap=my_value_codec)
Parameters:

  • store – A CosmosPartitionedItems, or a dol wrapper around one.

  • pk_value – The partition-key value, as stored (not passed through any key codec).

  • wrap (Optional[Callable]) – Applied to the child store before it is returned. Required when store is wrapped; wrap=lambda s: s explicitly asks for the bare child.

Return type:

Any

cosmodol.replace_item(store, k, v, *, etag=None)[source]¶

Full replace of the existing item at key k, optionally ETag-conditional.

Unlike store[k] = v (an upsert), this fails with ItemNotFoundError if the item does not exist, and with a precondition error if etag no longer matches.

Parameters:

  • store – A CosmosItems, or any dol wrapper around one. The write goes through store[k] = v, so every layer maps, checks or refuses it as usual; only the leaf’s upsert becomes a replace.

  • k – The key, as store[k] would take it.

  • v – The value, as store[k] = v would take it.

  • etag (Optional[str]) – If given, only replace when the stored item’s _etag still equals it.

Return type:

dict

Returns:

The stored document as Cosmos returned it (leaf form; system fields stripped if the leaf strips them).

cosmodol.resolve_credential(*, credential=None, connection_string=None, endpoint=None, key=None)[source]¶

Resolve a credential into a normalized form that can build a CosmosClient.

Cascade (first hit wins):

  1. Explicit credential= (with endpoint= for the URL)

  2. Explicit connection_string=

  3. Explicit endpoint= + key= (or just endpoint= + AAD)

  4. Env var AZURE_COSMOS_CONNECTION_STRING

  5. Env vars AZURE_COSMOS_ENDPOINT + AZURE_COSMOS_KEY

  6. Env var AZURE_COSMOS_ENDPOINT alone + DefaultAzureCredential

Returns:

{"url": "...", "credential": <obj>}

Return type:

dict

Raises:

ValueError – if no source resolves.

cosmodol.translate_cosmos_errors(*, key_arg=0, not_found_cls=<class 'cosmodol.errors.ItemNotFoundError'>, exists_cls=<class 'cosmodol.errors.ItemAlreadyExistsError'>)[source]¶

Decorator: translate Cosmos SDK exceptions into KeyError subclasses.

Auth errors and any other Cosmos errors propagate untouched. HTTP 429 throttling is wrapped in CosmosThrottleError so callers can distinguish it. See misc/docs/design_decisions.md §11.

Parameters:

  • key_arg (int | str) – Position (int) or name (str) of the key argument in the wrapped method’s signature. Used to populate KeyError(key). Default 0; for methods the user-facing key is typically at index 1 (self at 0).

  • not_found_cls (type[KeyError]) – Exception class to raise on CosmosResourceNotFoundError.

  • exists_cls (type[KeyError]) – Exception class to raise on CosmosResourceExistsError.

Return type:

Callable

cosmodol.validate_cosmos_id(k)[source]¶

Raise ValueError if k is not a valid Cosmos item id.

Cosmos may accept invalid ids on write but the item then becomes unreachable from the SDK. We fail loudly at write time. See misc/docs/cosmos_db_reference.md §”id rules”.

Return type:

None
